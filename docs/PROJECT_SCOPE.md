- Synthetic customer data

## What was intentionally removed
To keep the project focused, this version does not include:
- sanctions name-matching engine
- adverse-media screening
- beneficial-ownership analysis
- full SAR narrative generation
- ML anomaly-detection models
- production orchestration
- model governance documentation
- cloud deployment scripts

Those belong in a larger AML Analytics Investigator platform rather than this transaction-monitoring-focused portfolio project.
